Docs

Comment on any page, or any block, right where it is.

Easy Markup turns a WordPress page into a review copy. Editors point at a paragraph, a heading or an image and leave a note on it. Clients and reviewers do the same with a review link, no account needed. Every comment lands in one list you can resolve as you go.

Comment on a page

  1. Open any page while signed in as an editor or admin. Click Comment at the bottom right.
  2. Move the pointer over the page. The block under it is outlined.
  3. Click a block, or Tab to it and press Enter. The box shows which block you picked.
  4. Type the comment and click Send. Click a name under the box to mention a teammate; they get an email.
  5. For a note about the page as a whole, click Whole page.
  6. A picture of the page, with your block outlined, is saved with the comment, so editors see what you saw even after the page changes.
  7. Click Done commenting to use links and buttons on the page again.

You can also start from the admin bar: Markup > Comment on this page.

Comment in the editor

  1. In the block editor, select a block and click Comment on its toolbar. The Comments sidebar opens with the cursor in the box.
  2. Type and click Add comment.
  3. To comment on the page instead, choose Whole page above the box. Selecting another block switches back.
  4. The sidebar lists the page's comments, open ones first. Show selects the block a comment is on.
  5. Resolve marks a comment done; Show resolved brings it back into view.

Comments are tied to the saved page. If you added or moved blocks, save first so the comment lands on the right one.

Review links

  1. In the editor's Comments sidebar, open Review links.
  2. Say who it's for and how long it works: 7, 30 or 90 days, or until turned off.
  3. Tick Works on every page of the site for a whole-site link, or leave it for this page only.
  4. Click Make a review link, then Copy link and send it.
  5. The reviewer opens it and lands in comment mode. They give their name once and comment the same way an editor does.

Turn a link off from the sidebar or from Markup > Review links. Its guests lose access at once.

Manage comments

Markup in the admin menu lists every comment on every page, with the number of open comments on the menu itself. Filter by page and by open or resolved.

  • View on page scrolls to the block, outlines it and shows the comment.
  • Edit page opens the editor, where the sidebar has the same comments.
  • Resolve, Reopen and Delete work here too. Delete is permanent; Resolve keeps the comment.
  • Review links, under the list, shows every link with the page it works on, how many comments it brought in, and Turn off. Editors and admins make whole-site links here.

Settings

Admins find these under Markup > Settings.

Guest comment emails

Tick Send an email when a guest comments and list who should get them, one address per line or separated by commas (up to 20). Each comment left through a review link then emails everyone on the list with the page, the block and its first words, the comment, the guest's name, which review link they used, and links to the comment and to the full list.

Comments from editors and admins don't send these; they mention each other instead. Entries that aren't email addresses are left out with a message, and the switch stays off until the list has at least one address.

Page snapshots

On by default. Each comment left on the page saves a picture of the whole page as it looked, with the commented block framed. Snapshots show as thumbnails in the editor sidebar and the Markup list, and in View on page. Only people who can edit the page can open them; a guest email links to the snapshot behind a sign-in. Comments added in the editor sidebar have no snapshot. Turn it off with Save a picture of the page with each comment left on it.

Whole-site links are made by editors and admins (users who can edit others' pages). One link can bring in at most 30 comments an hour, across all its guests.

Install

  1. Download easy-markup.zip from the latest release.
  2. In WordPress, go to Plugins > Add New > Upload Plugin, choose the zip and activate it.
  3. Open any page and click Comment.

Needs WordPress 6.6 or later and PHP 8.1 or later. Activation creates two tables: {prefix}easy_markup_comments and {prefix}easy_markup_links.

For developers

How a block is identified

WordPress blocks have no saved IDs, so a block's ID is its place in the page content: b1, b2 and so on, counting every block, inner blocks included, in order. For people who can comment, each content block renders with two attributes. The header, footer and template are not numbered.

<p data-em-block="b7" data-em-type="core/paragraph">…</p>

A comment also keeps the block's first words, so it still finds its block after edits shift the numbers.

CSS custom properties

The color settings set --em-accent, --em-button and --em-button-text on :root. A theme can set them too.

Coding standards

The PHP passes the WordPress Coding Standards. composer lint runs PHPCS; every push to main lints, builds the zip, and releases the version in the plugin header.

Questions

Does a review link let someone edit the page?
No. It only lets them leave comments. They can't see other people's comments or anything in the admin.
What happens to a comment when the block is deleted?
The comment stays in the list with the block's type and first words. View on page tells you the block is no longer there.
Who gets emails?
People mentioned by handle in a staff comment (a handle is the part of their email address before the at sign), and, if guest comment emails are on, the addresses in Settings for each guest comment.
Where are snapshots kept, and who can see them?
In wp-content/uploads/easy-markup-snapshots, under random names, re-saved as JPEG at most 1600px wide. They're never linked directly: editors open them through a signed-in link that checks they can edit the page. Deleting a comment deletes its snapshot. Some things can look a little different in a snapshot than on screen, such as images from other sites, embeds and some web fonts.
Do visitors see anything?
No. Pages look the same to visitors; the Comment button and block attributes only appear for people who can comment.
